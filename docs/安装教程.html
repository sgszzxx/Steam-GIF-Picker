为什么默认使用 GifSnap，而不是 GIPHY API？

本扩展最初使用 GIPHY。开发期间在中国大陆的实际网络环境中发现：即使 GIPHY 官网能打开，其 API 接口（api.giphy.com）也可能连接失败或超时。 图片 CDN 与 API 是不同服务，能打开网页不代表能够搜索动图。某些大陆网络环境需要稳定、合规的国际网络连接（例如适用的网络代理，俗称「魔法网络」），才能正常使用 GIPHY API。具体情况取决于运营商、地区及网络配置，不能保证所有用户都一样。

遇到加载失败怎么办？

先确认数据源选择正确，点击「保存并加载」，再点「检测网络连接」，查看 API 与图片 CDN 的独立检测结果。GIPHY Key 错误、调用频率限制和网络超时是不同问题；如果仅 GIPHY API 不通，建议切回 GifSnap，而不是重复申请 Key。

官方资料：GifSnap API 文档 · GIPHY API Quickstart。大陆网络描述来自本项目实测，不是服务商对全国网络的官方结论。

旧版用户升级与常见问题

从旧的解压版迁移到 CRX：签名版有新的固定扩展 ID，不会自动继承旧版 API Key、收藏及历史。要保留原数据，请继续使用开发包中的解压版源码覆盖原安装目录、点击重新加载。不要删除原扩展或同时启用两份扩展。若决定转用 CRX，先停用旧版、保留旧数据，重新配置 Key；目前没有自动数据迁移。

CRX 安装被拒绝：Steam 版本或浏览器策略可能不接受第三方 CRX。不要关闭系统安全策略；联系发布者索取解压安装版，使用开发者模式的「加载已解压的扩展程序」。

看不到悬浮球：确认扩展启用、当前是好友聊天而不是商店/好友列表，关闭并重开聊天，必要时正常重启 Steam。

无法加载热门或搜索结果： 默认 GifSnap 不需要 Key；确认数据源并使用「检测网络连接」。只有切换到 GIPHY 才需要检查 Key 是否已保存。网络超时请参阅上方数据源与国内网络说明。

以后更新 CRX：只使用发布者以同一签名密钥打包的新版，安装是否支持直接覆盖需实机确认。更新后核对版本、扩展 ID 与收藏，不要先删除旧版。
