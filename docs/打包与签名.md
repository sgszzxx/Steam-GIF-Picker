## 后续生成同 ID CRX

安装 Python 与 cryptography (`python -m pip install cryptography`)；使用支持扩展打包的 Chrome/Chromium。先更新运行时 Manifest 版本号，执行：

```text
python tools/pack-crx.py --chrome "C:\Program Files\Google\Chrome\Application\chrome.exe" --key "D:\private\steam-gif-picker.pem" --out "Steam-GIF-Picker.crx"
```

脚本仅复制 12 个运行时白名单文件，使用 Chromium 自带打包功能，并验证签名及固定 ID。独立验证：

```text
python tools/verify-crx.py Steam-GIF-Picker.crx --runtime steam-gif-picker
```

发布 ZIP 只包含 CRX 和安装教程 HTML；开发 ZIP 仅工程文件与教程。禁止把私钥加入任一包。实际 Steam 拖入安装及同 ID 更新尚待实机确认。旧解压版本继续在原目录覆盖升级，不要给解压版强制添加公钥导致 ID 改变。
