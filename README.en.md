# Steam GIF Picker

[简体中文](README.md) · [Download](https://github.com/sgszzxx/Steam-GIF-Picker/releases/latest) · [Issues](https://github.com/sgszzxx/Steam-GIF-Picker/issues)

An independent Manifest V3 extension for GIF browsing and sharing in the Windows Steam desktop chat client. Current version: **0.1.29**. Not affiliated with Valve or any media provider.

Features: GifSnap search without an API key by default, optional GIPHY with your own key, favorites, local search history, horizontal wheel browsing, a three-column layout, one-click sending, bounded deduplication, local GIF compatibility checks and WebP conversion.

Download the Release ZIP and extract it. Open the bundled Chinese illustrated HTML guide. In Steam, open a store link in a new tab, enter `chrome://extensions/` in that tab's editable address bar, enable developer mode and drop the signed CRX into the page. Reopen a chat. Compatibility depends on the Steam client; do not disable system security protections.

GifSnap and GIPHY are online third-party services. The extension does not include a proxy or a project-operated server. The configurable 2 MB GIF link threshold is empirical, not an official Steam limit. WebP conversion can be lossy; upload only media you are authorized to use and redistribute.
